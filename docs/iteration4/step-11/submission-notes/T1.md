# T1 — the chain on a second disease (Bloom syndrome): submission note

**Standing:** written 2026-09-25 from entry
[156](../methodology/156-the-chain-on-bloom-syndrome.md); re-check before the submission is assembled.

## The finding, in one sentence

Iteration 4's Track 2 chain runs end to end on Bloom syndrome (gene `BLM`) and proposes a
**different** drug set (Jaccard 0.095 against MVA's), but **not by configuration alone**: four
tools keep their case in Python constants and seven write MVA text into their outputs, so it took
one new 378-line driver and 136 text corrections — **H096 is refuted as registered**.

## Rubric: what it earns

## Limitations and what would change the conclusion

- Clause (a) would hold after four `--case` flags and moving seven strings into the plans; re-run
  this entry then.
- A drug tested in a *Blm* mouse, or a PRISM release that labels REP.1M compounds' phase, would
  give Bloom's G2 / G3 something to say.
- The K2 mapping and the G2 table are unreviewed manual judgements.
