# S1 — the screen-wide PRISM sweep (generator G3): submission note

re-check before the submission is assembled.

## The finding, in one sentence

Over **all 613** launched drugs PRISM measured on ≥ 3 rhabdomyosarcoma lines and ≥ 20 lines per
aneuploidy arm, **no drug reaches q < 0.10 in either contrast** (best q 0.122 RMS, 0.287
aneuploidy), so H093 is refuted — while the identical code finds dabrafenib and vemurafenib for
melanoma lines at q ≈ 10⁻⁹ across 2,032 drugs.

## Limitations and what would change the conclusion

- A drug-approval join (ChEMBL max phase 4) over the 1,489 unclassified REP.1M / REP.300
  compounds — the ones measured on all 14 RMS lines — could add testable drugs with real RMS
  power; that is the one analysis that could overturn "none".
- A dose-response release (20Q2 AUC) was not swept; entry 151 showed signals halve there.
