# Documentation index

**Standing:** the single index. Every live document in the repository is listed here; if a
doc is not on this page it does not exist yet. Last checked 2026-08-29.

Each topic has exactly one owner. Before writing a new doc, extend the owner below.

Work is grouped by **step**, and every step declares one research goal. Everything already
built — the delivery, the object store, the warehouse, the exploration toolkit — is
[step 0](step-0/README.md), which is machinery and takes no hypotheses. From
[step 1](step-1/README.md) on, each step carries a goal and a register of falsifiable
claims: [`method.md`](method.md) is how that works. The pages below the steps are
cross-step — they describe the whole project, not one phase of it.
